# 바이오하자드(1996) 한글화 번역 가이드

원문은 **일본어판(BIOHAZARD)** 이다. `en` 필드(북미판 문장)는 참고용일 뿐이며, 북미판은 컷신 자막이 비어 있거나 내용이 다른 경우가 많다. 번역은 항상 일본어 원문의 의미와 뉘앙스를 기준으로 한다.

## 파일 형식

각 항목:

```json
{"id": 12, "jp": "<C4:0>\n　　　　　　そうするか<C4:1><PAGE:70>...", "en": "...", "ko": "", "refs": ["STAGE1/ROOM1000.RDT#12", ...]}
```

- `ko`만 채운다. 다른 필드는 절대 수정하지 않는다.
- `refs`는 이 문장이 나오는 방(ROOM 번호)과 메시지 번호다. 같은 방의 문장들은 대체로 연속된 장면이다.

## 제어 태그 (반드시 지킬 것)

- `<END:n>`, `<PAGE:n>`, `<C4:n>`, `<COL:n>`, `<ITEM:n>`, `<YESNO:n>` 태그는 **원문과 같은 순서·같은 개수·같은 값**으로 그대로 둔다.
- `<PAGE:n>`은 다음 페이지(자막에서는 n이 표시 시간)다. 페이지를 새로 만들거나 없애지 않는다.
- `<END:n>` 뒤에 붙은 문자(예: `<END:0>　　　`)는 게임이 읽지 않는 쓰레기 데이터이므로 번역문에서는 버린다.
- `\n`(줄바꿈)은 의미에 맞게 조정해도 되지만 **한 페이지는 최대 2줄**이다.
- 원문 첫머리가 `\n`으로 시작하는 한 줄짜리 문장(창의 2번째 줄에 표시됨)은 번역도 `\n`으로 시작하게 둔다.
- 줄 앞의 전각 공백(`　`)으로 맞춘 가운데 정렬은 **빌드 도구가 자동으로 다시 계산**한다. 번역문에는 정렬용 공백을 넣지 않는다.
  예: `"<C4:0>\n　　　　　　そうするか<C4:1>..."` → `"<C4:0>\n그런가<C4:1>..."`

## 글자 수 제한

- 한 줄 최대 **20칸**. 한글·영문·숫자·문장부호는 1칸, 띄어쓰기(반각 공백)는 0.5칸.
- `<YESNO:n>`이 있는 페이지에서 **2번째 줄은 9.5칸 이하** (오른쪽에 "예 / 아니오"가 그려짐).
- 아이템 이름은 12칸 이하.
- 게임 화면이 작으므로 간결하게. 의미를 살리되 군더더기는 줄인다.

## 사용 가능한 문자

- 한글 완성형 음절, 영문 대소문자, 숫자
- 문장부호: `. , ! ? : / - ' " ( ) 「 」 『 』 … · ~` 와 반각 공백
- `!?`는 `?!` 대신 한 글자 `⁉`를 써도 된다.
- 전각 문장부호(？！，。)는 쓰지 말고 반각(? ! , .)을 쓴다. 일본어 `・・・`/`…`는 `…`로.
- `S.T.A.R.S.`는 그대로 쓰면 전용 글리프로 바뀐다.

## 문체

- **조사(examine) 메시지**: 평서형 해라체. `～だ/～である` → `～다/～이다`, `～ようだ` → `～ 것 같다`.
  예: `特に気になるところはない` → `특별히 신경 쓰이는 곳은 없다`
- **질문(YESNO)**: `～ますか？` → `～할까요?` / `～합니까?` 중 짧은 쪽. 예: `取りますか？` → `가져갈까요?`
- **대사**:
  - 크리스·질·배리·웨스커 등 S.T.A.R.S. 동료끼리는 반말. 웨스커는 상관답게 단호한 반말.
  - 레베카(신입)는 크리스에게 존댓말(해요체), 크리스는 레베카에게 반말.
  - 배리는 질에게 다정한 반말, 질도 배리에게 반말.
  - 연구원 일지·편지 등은 원문 문체에 맞춘다.
- 자막은 말하는 속도에 맞게 짧고 자연스럽게.
